# Security

Please report a vulnerability through a private GitHub security advisory in
this repository. Do not include exploit details in a public issue.

Supported releases receive security fixes on the latest patch release. Older
releases may be asked to upgrade.

lintocaml reads compiler artifacts and, with `--fix`, rewrites source files. A
report involving malformed artifacts, path handling, or unsafe edits is within
scope even if it does not permit code execution.
